📖 操作手册 · SQL 妙妙小工具

导入 CSV → 描述问题 → 生成/校验 SQL → 在浏览器里真的把 SQL 跑出来（sql.js/SQLite WASM），结果一键导出。数据只在本机、不上传。

第 1 步 · 导入 CSV
🎯 目的：把 CSV 变成可查询的表
⌨️ 输入：.csv/.txt 文件或粘贴的 CSV（首行为列名）
🖱️ 操作：上传或粘贴 → 点"导入建表"，建成表 data
📤 输出：提示"已建表 data(N 行，列…)"，记住最终列名
第 2 步 · 描述问题与输出
🎯 目的：想清楚算什么、结果文件叫什么
⌨️ 输入：自然语言问题 + 输出文件名
🖱️ 操作：两框各填一行（问题会喂给 AI 生成）
📤 输出：为后两步做准备
第 3 / 4 步 · 生成 & 校验 SQL
🎯 目的：得到一条针对表 data 的 SQL
⌨️ 输入：手写 SQL；或用 AI 按钮(需 API)
🖱️ 操作：手写 FROM data；或 ✨生成/🔍校验
📤 输出：SQL 框出现可执行草稿
第 5 步 · 浏览器内执行
🎯 目的：真正跑出结果并导出
⌨️ 输入：第 3/4 步的 SQL
🖱️ 操作：等"引擎已就绪"→点▶运行；报错则查表名(data)/列名/语法
📤 输出：结果表 + 可导出结果 CSV

原理：sql.js 是编译成 WebAssembly 的 SQLite，数据库引擎跑在你浏览器里，故能真执行、无需后端。
